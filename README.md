# J.H Planner

Windows 向けのプロジェクト管理デスクトップアプリケーションです。WBS、ガントチャート、
ボード、進捗分析をローカルの `.wbs` ファイルで扱えます。

このリポジトリは**配布専用**です。インストーラーと更新情報のみを公開しています。

## ダウンロード

- [最新版をダウンロード](https://github.com/pei-jz/jh-planner-releases/releases/latest)

対応環境: Windows 10 / 11（x64）

各 Release には NSIS インストーラー、SHA-256 チェックサム、利用許諾、第三者ライセンス通知を添付しています。
インストール後は、アプリが起動時に更新を確認し、新しい版があれば確認のうえ適用します。

## 価格

- **ローカル機能**: 無償。`.wbs` ファイルでの作成・編集・分析はオフラインで完結します。
- **Server Mode**: 有償。共有保存、メンバー管理、同時編集、チャット、監査などのチーム機能には
  別途 J.H Planner Server の契約が必要です。
